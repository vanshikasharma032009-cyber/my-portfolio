# Vanshika Portfolio

My personal portfolio website: Home, About, Projects, Skills and Contact pages, with an AI tools globe, marquees and a chatbot.

Built with HTML, CSS and JavaScript.

## Files
- `index.html` - page structure
- `style.css` - design and animations
- `script.js` - interactions, chatbot, globe, pages
- `vanshika.jpg`, `chatbot-logo.png` - images

## Run
Open `index.html` in a browser.
